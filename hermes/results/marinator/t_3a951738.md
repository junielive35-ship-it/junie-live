# Marinator Result: t_3a951738

## Outcome

Completed. The main `junie-live` Chat Agent path no longer exposes the `marinator` plugin toolset in normal CLI/Telegram toolsets, while `senior-dev` retains `marinator` and `senior` for Kanban-backed execution and result reporting.

## Root Cause

The live/distribution path had the `marinator-delegation` plugin enabled for the main `junie-live` profile and also enabled the `marinator` toolset for Chat Agent CLI/Telegram sessions. That made `marinator_delegate` directly visible to the Chat Agent, bypassing the intended `create_senior_task` -> `senior-dev` -> `marinator_delegate` -> `senior_dev_task_result` boundary. Several Chat Agent-facing docs/skills/prompts still instructed direct Marinator use, which reinforced the wrong execution path.
