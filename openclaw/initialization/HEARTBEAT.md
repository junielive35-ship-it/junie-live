# HEARTBEAT.md

Keep this short. Use it only for lightweight recurring checks that are useful for the assigned project.

During bootstrap, either leave this mostly empty or add a small checklist such as:

- Check for urgent team questions or mentions.
- Check open PR/CI status when there is active work.
- Check stale blockers or approvals.
- Check code mutex status when code work is active or queued.
- Check relevant bug/analytics alerts if configured.

Do not create fixed schedules here unless the project explicitly needs them. Schedules are project-dependent.
